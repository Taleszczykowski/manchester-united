# Manchester United | Fan Landing Page

A responsive, English-language fan landing page built with plain HTML, CSS and JavaScript.

## Run it
Open `index.html` in a web browser. No installation or build tools are required.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation, reveal effects and animated statistics

## Design notes
- The stadium illustration and decorative graphics are drawn with inline SVG and CSS.
- Inter and Barlow Condensed load from Google Fonts; browser fallback fonts are used offline.
- Motion respects the operating system's `prefers-reduced-motion` setting.
- This is an independent fan project and is not affiliated with the club.
- Historical details and honours are based on the supplied Wikipedia article: https://en.wikipedia.org/wiki/Manchester_United_F.C/
